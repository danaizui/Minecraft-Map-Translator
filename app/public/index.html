使用说明

1. 选择翻译对象

可以添加：整合包根目录（包含 mods、config、saves）、.minecraft 文件夹、saves 存档目录、单个世界文件夹，或 mods 文件夹。

2. 会自动翻译什么

  • 任务书：FTB Quests 的 SNBT/语言文件、Better Questing 的 JSON、旧版 NBT。
  • 模组语言文件：读取 mods 里的 en_us.json / en_us.lang，在 resourcepacks 生成中文资源包，不修改 jar。
  • 世界文本：告示牌、成书、文本展示实体、NPC 名字、计分板、CustomNPCs 对话；命令方块只翻译 JSON 显示文本，不动命令语法。

3. 在游戏里生效

资源包会被放到整合包的 resourcepacks/，进入游戏后在「选项 → 资源包」启用；任务书语言文件通常自动生效。游戏语言请设为中文。

4. 安全与撤销

所有被修改的文件都会备份到程序目录的 backup 文件夹。点「撤销上次」可恢复最近一次翻译；保留最近 10 次记录。建议翻译前关闭游戏。

5. 关于机器翻译

默认使用微软必应的免费公开接口，无需 API Key；长文本会切分并保留 %s、§a、{0} 等占位符。翻译质量取决于引擎，专有名词可能不准确，可在生成的资源包里手动校对。

提示：第一次翻译整包可能有几万条文本，需要较长时间；再次运行会命中缓存，速度会快很多。
