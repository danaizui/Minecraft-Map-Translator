【它是什么】
  一个免安装的 Windows 小工具，可以批量把英文的 Minecraft 整合包、
  冒险地图、任务书翻译成中文。翻译使用免费的在线机器翻译，
  不需要注册账号，也不需要 API Key。

【翻译哪些内容】
  1. 任务书
     - FTB Quests（.snbt 任务章节、lang 语言文件、旧版 .nbt）
     - Better Questing（.json）
     - HQM 及其它常见任务书文件
  2. 模组语言文件
     - 读取 mods 文件夹里每个模组自带的 en_us.json / en_us.lang
     - 在整合包的 resourcepacks 文件夹里生成一个中文资源包
     - 不会修改、也不会重新打包任何 mods 里的 .jar 文件
  3. 地图世界文本
     - 告示牌、成书、文本展示实体
     - 村民 / 实体 / 物品的自定义名称、物品描述（Lore）
     - 计分板、队伍名称
     - CustomNPCs 对话（JSON）
     - 命令方块：只翻译其中的 JSON 显示文字，绝不改动命令本身
  4. 可选：Patchouli 模组指南书（在界面里勾选“模组指南书”）

  不翻译：成就进度、配方、音效、资源路径、代码等非显示文本。
  支持 Minecraft 1.12.2 到 1.21.x 的整合包。

【开始使用】
  1. 双击桌面上的「MC地图翻译器」快捷方式。
     也可以打开本文件夹，双击「启动.vbs」（无窗口启动）；
     或者双击「启动.cmd」（会显示黑色控制台，方便排查问题）。
  2. 点击「＋ 添加文件夹」，选择：
     - 整合包根目录（里面有 mods、config、saves 的那一层），或
     - saves 存档文件夹（会翻译里面所有存档），或
     - 单个地图 / 存档文件夹（里面有 level.dat），或
     - .minecraft 文件夹
     可以一次添加多个文件夹。
  3. 在左侧选择翻译范围、引擎、目标语言（简体 / 繁体）。
  4. 点击底部「开始翻译」，等待完成即可。
  5. 第一次翻译整包可能比较久（几十分钟到几小时，取决于文本量）；
     以后再次翻译会命中缓存，速度会快很多。

  ★ 建议：翻译前先关闭 Minecraft，并备份重要存档。

【让翻译在游戏里生效】
  - 资源包：翻译完成后，程序会把「MC翻译_中文资源包」放进
    整合包的 resourcepacks 文件夹。进入游戏后打开
    「选项 → 资源包」，把该资源包移到右侧并启用。
  - 任务书：FTB Quests 的中文语言文件（zh_cn.snbt）通常会自动生效；
    如果没生效，重启游戏或在任务书里切换一次语言。
  - 游戏语言：请确认游戏语言设置为「简体中文」。
  - 服务端 / 联机：世界文本（告示牌、成书等）保存在存档里，
    翻译后请把存档同步到服务器；资源包需要每个客户端都启用。

【备份与撤销】
  - 每次翻译前，程序会把所有将要修改的文件备份到本文件夹的
    backup 目录，修改清单保存在 data\runs。
  - 点击右上角「撤销上次」，可以把最近一次翻译修改的文件
    完整还原（包括删除新生成的资源包文件）。
  - 程序保留最近 10 次翻译记录；更早的会自动清理。
  - 预览模式：勾选「预览模式」后只翻译、不写入任何文件，
    适合先看看实际翻译效果。

【译文预览（预览模式）】
  1. 在左侧勾选「预览模式」，然后点击「开始翻译」。
  2. 翻译完成后，右侧会自动切换到「译文预览」标签，
     逐条显示「原文 → 译文」，并标注来源文件和键名。
  3. 顶部搜索框可以按原文、译文、文件名或键名筛选。
  4. 界面上最多显示前 300 条样例；点击「打开完整预览文件」，
     可以在记事本中查看全部译文（最多 5000 条），
     完整文件路径为 data\preview.txt。
  5. 预览模式不会写入任何游戏文件，也不会生成资源包；
     确认效果满意后，取消勾选「预览模式」再正式翻译一次即可。
  6. 普通（非预览）翻译完成后同样会保留前 300 条样例，
     方便快速检查译文质量。

【常见问题】
  Q: 双击没反应 / 界面没有打开？
    先试「启动.cmd」，它会显示错误信息；也可以查看 logs 文件夹。
    如果界面被关闭但后台仍在运行，重新双击快捷方式会再次打开界面。

  Q: 提示“必应请求过于频繁”或翻译失败？
    免费接口有频率限制。可以把「同时请求」调成 1，
    把「请求间隔」调大（例如 500–1000 毫秒），然后再试。
    也可以在「翻译引擎」里换成 MyMemory（备用，速度较慢）。

  Q: 翻译卡住 / 想停止？
    点击「停止」，当前批次结束后会停下，已完成的文件都已备份。

  Q: 某些词翻译得不对？
    机器翻译无法保证专有名词准确。可以翻译后手动修改
    生成的资源包里的 zh_cn.json，或修改任务书语言文件。

  Q: 杀毒软件报警？
    程序本身不联网做坏事，只是调用微软必应的公开翻译网页接口。
    如果被拦截，请添加信任；也可以直接运行 启动.cmd 查看行为。

  Q: 端口被占用 / 同时开了多个？
    程序会自动使用 17321–17340 之间第一个可用端口；
    重复启动只会打开已运行程序的界面，不会重复翻译。

  Q: 想换电脑或移动文件夹？
    把整个「翻译软件」文件夹复制走即可，程序是绿色免安装的。
    但移动后请重新创建桌面快捷方式（或直接运行 启动.vbs）。
    （数据、备份、缓存都在这个文件夹里。）

  Q: 下载的地图是 zip / 整合包是压缩包？
    请先解压成文件夹，再选择解压后的目录。
    程序不直接读取 .zip / .rar 压缩包（mods 里的 .jar 除外）。

  Q: 支持基岩版（手机 / Win10 版）吗？
    不支持。本工具只处理 Java 版的整合包、存档和资源包格式。

【命令行用法（可选，进阶）】
  在地址栏输入 cmd 打开本目录，然后：

    runtime\node.exe app\cli.js "D:\Minecraft\MyPack"
    runtime\node.exe app\cli.js "D:\Minecraft\MyPack" --engine mymemory
    runtime\node.exe app\cli.js "D:\Minecraft\saves\MyMap" --dry-run
    runtime\node.exe app\cli.js --undo
    runtime\node.exe app\cli.js --help

【文件结构】
  app\            程序代码（请勿删除）
  runtime\        内置 Node.js 运行环境
  启动.vbs        无窗口启动脚本（快捷方式指向它）
  启动.cmd        带控制台的启动脚本（排错用）
  backup\         文件备份
  data\           配置、缓存、翻译记录、上次报告
  logs\           运行日志
  test\           自动化测试（可删除）
  app.ico         程序图标
  README.txt      本说明

【安全提示】
  - 所有修改都有备份，但仍建议自行保留一份重要存档。
  - 世界文本一旦被翻译就会写入存档，撤销可以恢复最近一次。
  - 请勿在翻译过程中同时用 Minecraft 打开同一个存档，
    否则可能造成存档损坏。
